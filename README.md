# Event Management System

A comprehensive event and venue management system built with Spring Boot and Hexagonal Architecture.

## Features

- ✅ Hexagonal Architecture (Ports & Adapters)
- ✅ RESTful API for Events and Venues management
- ✅ JWT-based Authentication & Authorization
- ✅ Advanced JPA relationships and optimizations
- ✅ Database migrations with Flyway
- ✅ Comprehensive error handling with RFC 7807
- ✅ Structured logging
- ✅ Unit and Integration tests
- ✅ Docker support with multi-stage builds
- ✅ Monitoring with Spring Boot Actuator
- ✅ OpenAPI documentation

## Tech Stack

- **Java 17**
- **Spring Boot 3.2.0**
- **Spring Security with JWT**
- **Spring Data JPA**
- **H2 / MySQL Database**
- **MapStruct** for object mapping
- **Flyway** for database migrations
- **Docker & Docker Compose**
- **JUnit 5 & Mockito** for testing
- **OpenAPI 3** for documentation
